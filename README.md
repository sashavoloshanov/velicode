# Velicode

Portfolio & order form website for iOS, Android & Web app development.

## Stack

- **Framework:** Next.js (React, TypeScript)
- **Styling:** Tailwind CSS v4
- **Icons:** Lucide React + custom SVGs
- **Hosting:** Vercel
- **Form backend:** Google Sheets API (TODO)
- **Analytics:** Vercel Analytics (TODO)

## Features

- Bilingual (EN / UA) with language toggle
- Dark / Light theme toggle
- Responsive design (mobile-first)
- Project portfolio with store links
- Contact form with auto-reply
- FAQ accordion
- Privacy Policy page

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deployment

Push to `main` — Vercel auto-deploys.
